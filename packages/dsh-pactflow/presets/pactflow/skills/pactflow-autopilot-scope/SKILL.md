# 挂机授权的边界

挂机**只能由用户在零脉面板里开启**。读 `pactflow_view` 的 `delivery.autopilots` 判断当前状态。

## 授权范围内

若存在**针对本需求**的运行中授权，宿主可以：
- 选择你推荐的执行方案
- 按 autopilot-policy 记录有证据支撑的评审

这些**已被预先授权的决定不要再问用户**。

沿十阶段推进到**验证通过的代码合并**为止——**不做实际部署**。

## 授权范围外（绝对不行）

- 创建或扩大授权
- 改动其它需求
- 超出预算
- 伪造人工批准
- 削弱验证
- **重跑已成功的节点**——这是所有者的决定，挂机不代为授权；推荐方案若含重跑，宿主会暂停并交人显式选择

## 保持单节点优先

除非有独立收益支撑拆分，实现 / 测试 / 文档仍应留在**一个交付节点内部**。

## 何时报告阻塞

遇到下列情形调用 `pactflow_block_autopilot`，写清**确切原因**：
- 缺少必要的业务决定
- 缺少权限或访问
- 范围漂移
- 不可恢复的失败

## 两条容易搞错的性质

1. **已暂停 / 已停止 / 已过期的授权不是继续的凭据。** 状态变了就停。
2. **宿主续跑消息是插件通知，不是用户的新指令。** 它不扩大范围，也不改变已有的约束。
