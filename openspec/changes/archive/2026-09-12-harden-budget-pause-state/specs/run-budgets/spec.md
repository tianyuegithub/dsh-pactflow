# run-budgets (delta)

## ADDED Requirements

### Requirement: 重试预算耗尽必须进入持久暂停而非仅异常拒绝

当节点的重试预算耗尽，宿主 SHALL 将该节点置入**持久暂停状态**（落账、进入投影），而不是仅以异常表达拒绝。暂停节点 MUST NOT 被派发或再次重试（准入对其失败关闭并指名「等待人工恢复」）；恢复 MUST 经由显式的人工动作（`resumeNode`）将节点复位为就绪（依赖仍满足时），且暂停与恢复都 MUST 留下可审计的历史。暂停状态 MUST 可从快照/投影与客户端读出。

#### Scenario: 预算耗尽进入持久暂停

- **WHEN** 对已耗尽重试预算的节点再次触发重试
- **THEN** 节点进入持久暂停状态并落账，后续派发与重试对其失败关闭并指名「等待人工恢复」

#### Scenario: 显式恢复后可再派发

- **WHEN** 人对暂停节点执行显式恢复且其依赖均满足
- **THEN** 节点复位为就绪并可正常派发；暂停与恢复在历史中可审计

#### Scenario: 暂停状态对人与模型可见

- **WHEN** 读取项目快照或打开客户端
- **THEN** 暂停节点以明确的「已暂停（等待决策）」呈现，而非以瞬时失败的形态出现
