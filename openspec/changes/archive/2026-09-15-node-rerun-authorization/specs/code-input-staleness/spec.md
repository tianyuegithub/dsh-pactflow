## ADDED Requirements

### Requirement: 过期检测必须在重跑授权路径上真实生效

代码输入过期检测 SHALL 在已成功节点的重跑授权路径上被真实调用，MUST NOT 停留为不可达实现。检测 SHALL 以**重新解析的依赖当前提交**与该节点上次运行记录的提交比对，过期项 MUST 在授权决策点对人可见，且 MUST 至少包含依赖标识、分支、上次记录提交与当前提交四项。

检测结果 MUST NOT 自动决定是否重跑——它是呈现给人的决策依据，不是自动推进的触发条件。检测本身失败或依赖当前提交无法解析时 SHALL 显式报告，MUST NOT 以「无过期项」冒充。

#### Scenario: 检测在重跑授权路径上被调用

- **WHEN** 所有者对一个已成功且依赖上游已变更的节点打开重跑授权
- **THEN** 过期检测被调用并返回该依赖的过期项，四项字段齐备

#### Scenario: 检测不自动触发重跑

- **WHEN** 检测发现存在过期依赖
- **THEN** 不发生任何自动重跑或状态变更，节点仍为 `succeeded`，等待人的决定

#### Scenario: 依赖当前提交不可解析时显式报告

- **WHEN** 某依赖的当前提交无法解析（远端不可达、引用缺失等）
- **THEN** 授权界面显式报告该依赖不可解析，MUST NOT 把它呈现为「未过期」
