# project-handover (delta)

## MODIFIED Requirements

### Requirement: 项目必须可导出只读移交摘要

Host SHALL 提供一个只读入口，从项目投影派生移交摘要，至少包含：项目身份与修订、Git 远端与默认分支、各需求的当前阶段与修订、DAG 节点状态、**每个已验证运行的精确 Git 产物（分支与提交）**、**尚未完成的清理责任**（含被标记保留的失败现场），以及**包版本与兼容事件生产者（reader）版本**。该入口 MUST NOT 修改任何状态，且 MUST 对在线与冷会话都给出一致结果。

#### Scenario: 摘要包含阶段与精确产物

- **WHEN** 对一个已有成功运行的项目请求移交摘要
- **THEN** 摘要包含该项目当前需求阶段，以及该运行的精确分支与提交

#### Scenario: 未完成责任必须出现在摘要中

- **WHEN** 项目存在待处理或被保留的清理责任
- **THEN** 摘要列出这些责任（并标明是否为保留的失败现场）

#### Scenario: 已完成清理不计入未完成责任

- **WHEN** 某清理责任已成功完成
- **THEN** 摘要的未完成责任列表不含该条

#### Scenario: 无项目时干净返回

- **WHEN** 会话尚未绑定项目
- **THEN** 摘要的项目为 null，且产物与未完成责任列表为空

#### Scenario: 摘要携带包版本与 reader 版本

- **WHEN** 请求移交摘要
- **THEN** 摘要携带当前包版本与兼容事件生产者（reader）版本，使旧日志的读取版本可追溯

#### Scenario: 版本字段来自构建与注册事实而非调用方输入

- **WHEN** 计算包版本与 reader 版本
- **THEN** 二者取自包构建版本与已注册的事件生产者版本，不由调用方提供或模型自述
