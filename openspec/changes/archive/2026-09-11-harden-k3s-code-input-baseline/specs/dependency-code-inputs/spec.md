## ADDED Requirements

### Requirement: 远端执行路径必须同样折入代码输入

对于在远端容器中执行的 Run（K3s），Host SHALL 把每个代码输入依赖的**精确成功提交**随任务输入下发；执行容器 SHALL 在施工前按精确提交取回并合并这些输入，使后序远端任务从依赖产出的树开始。折叠 MUST 以精确提交表达，MUST NOT 依赖可移动分支；取回或合并失败 MUST 失败关闭。折叠不得被当作任务交付：Worker 自身改动 MUST 以折叠后的基线衡量。

本地工作树方面，Host MUST 不折入这些输入（容器已折入），以便对远端返回提交做精确 fast-forward。

#### Scenario: 远端后序任务看到前序成果

- **WHEN** A 在真实集群成功提交一个文件，B 声明 A 为代码输入并在真实集群派发
- **THEN** B 的容器基线包含 A 的该提交，B 不因缺少前序文件而失败；B 的返回提交可被本地工作树精确 fast-forward

#### Scenario: 代码输入不可获取或冲突时失败关闭

- **WHEN** 某个代码输入的精确提交无法取回，或与任务基线合并冲突
- **THEN** 容器在该节点上失败关闭并给出原因，不静默忽略该输入

#### Scenario: 折叠本身不算交付

- **WHEN** 容器折入代码输入但 Worker 未产生任何自身提交
- **THEN** 该 Run 判为失败（不以折叠产生的提交冒充交付）

#### Scenario: 换基线无法通过结果校验

- **WHEN** 任务输入中的代码输入集合被替换（精确提交变化）
- **THEN** 规格摘要随之变化，远端结果因摘要不符而被拒绝
