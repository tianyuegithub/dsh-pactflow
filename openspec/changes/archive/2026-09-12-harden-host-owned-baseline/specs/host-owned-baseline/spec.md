# host-owned-baseline (delta)

## ADDED Requirements

### Requirement: 宿主自有验收基线必须在候选提交上强制执行

用户 SHALL 能按工作区登记宿主自有验证命令（基线资产），存储于任务仓之外、人所有。收口的隔离复验 SHALL 在确定候选提交上**先于任务验证执行基线**，其结果以独立标识（host-baseline 来源）进入验证证据与执行计数。基线一经登记 MUST 在每次收口执行，MUST NOT 被任务侧配置、验证策略或模型省略或修改；基线失败 SHALL 阻断收口并指名失败的基线命令。

#### Scenario: 基线在候选提交上执行并独立标识

- **WHEN** 收口对某需求的交付构件执行隔离复验且该工作区登记了基线
- **THEN** 基线命令在候选提交上执行，其证据带 host-baseline 来源标识，计入验证执行数

#### Scenario: 任务改弱自身测试但基线仍拦截

- **WHEN** 任务提交削弱了自己的测试且这些测试在候选提交上通过
- **THEN** 宿主基线仍照常执行；基线失败时收口失败关闭（对照：仅任务验证通过不足以通过收口）

#### Scenario: 未登记基线时行为不变

- **WHEN** 工作区没有登记任何基线
- **THEN** 收口行为与现状完全一致

#### Scenario: 任务侧不可触及基线

- **WHEN** 检查 Agent 面工具与任务提交的影响
- **THEN** 不存在读取或修改基线的工具路径；任务对验证配置的任何改动都不影响基线的存在与内容
