## Purpose

约束单次工作的**有限性**：重试次数与输出体积必须有有界预算；预算触及时必须显式说明原因并可被识别，不得静默继续尝试或静默截断降级。

## ADDED Requirements

### Requirement: 重试次数必须有界且显式拒绝

Host SHALL 为单个节点的重试设定有界的最大尝试次数。当下一次尝试将超出该预算时，Host MUST 拒绝该重试并给出显式原因（包含实际尝试数与预算值），MUST NOT 继续无限重试。

#### Scenario: 预算内的重试被允许

- **WHEN** 下一次尝试仍在预算内
- **THEN** 重试被接受

#### Scenario: 超出预算的重试被拒绝并说明原因

- **WHEN** 下一次尝试将超出预算
- **THEN** 重试被拒绝，错误信息包含实际尝试数与预算值

### Requirement: 输出体积必须有界且截断可见

Host SHALL 为单个观测的输出/日志文本设定有界的字节预算。文本超出预算时，保留内容 MUST 落在预算内，并 MUST 附带显式截断标记与原始字节数；MUST NOT 静默丢弃超出部分。

#### Scenario: 预算内文本原样保留

- **WHEN** 文本未超出字节预算
- **THEN** 返回原文且标记为未截断

#### Scenario: 超预算文本被有界截断且可见

- **WHEN** 文本超出字节预算
- **THEN** 返回文本落在预算内、标记为已截断、并记录原始字节数
