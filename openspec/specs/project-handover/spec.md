# project-handover Specification

## Purpose
让项目可被**只读移交**：导出当前项目身份、各需求阶段、精确 Git 产物引用与未完成责任，且不依赖插件继续运行、不修改任何状态——使「数据还在但没有 reader」不成为事实上的丢失。

## Requirements

### Requirement: 项目必须可导出只读移交摘要

Host SHALL 提供一个只读入口，从项目投影派生移交摘要，至少包含：项目身份与修订、Git 远端与默认分支、各需求的当前阶段与修订、DAG 节点状态、**每个已验证运行的精确 Git 产物（分支与提交）**、以及**尚未完成的清理责任**（含被标记保留的失败现场）。该入口 MUST NOT 修改任何状态，且 MUST 对在线与冷会话都给出一致结果。

#### Scenario: 摘要包含阶段与精确产物

- **WHEN** 对一个已有成功运行的项目请求移交摘要
- **THEN** 摘要包含该项目当前需求阶段，以及该运行的精确分支与提交

#### Scenario: 未完成责任必须出现在摘要中

- **WHEN** 项目存在待处理或被保留的清理责任
- **THEN** 摘要列出这些责任（并标明是否为保留的失败现场）

#### Scenario: 已完成清理不计入未完成责任

- **WHEN** 某清理责任已成功完成
- **THEN** 摘要的未完成责任列表不含该条

#### Scenario: 无项目时干净返回

- **WHEN** 会话尚未绑定项目
- **THEN** 摘要的项目为 null，且产物与未完成责任列表为空
